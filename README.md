## About Me

I am a **Data Platform Engineer and Analytics Engineer** with 5+ years of experience across data engineering, analytics engineering and business intelligence.

I build reliable data platforms and analytical solutions — from ingestion and transformation to modelling, reporting and decision-ready insights. My experience spans **AWS, Azure, Microsoft Fabric, Snowflake, BigQuery, dbt, Airflow, Terraform, Docker, Python, SQL and Power BI**.

My work has included designing ETL/ELT pipelines, building cloud data platforms, implementing analytics engineering workflows, improving data quality, automating reporting, and developing business intelligence solutions across fintech, aviation, healthcare technology and retail.

## Featured Data Engineering Projects

### 📰 [Bing News Sentiment Analysis — Microsoft Fabric](https://github.com/Musili-Adebayo/Bing-New-Search-Azure-Data-Engineering-Project-using-Microsoft-Fabric)
An end-to-end Microsoft Fabric data engineering solution that ingests Olympic news through the Bing News API, transforms data incrementally, applies sentiment analysis with SynapseML, visualises results in Power BI and triggers alerts through Data Activator.

**Tech:** Microsoft Fabric • Data Factory • Lakehouse • PySpark • SynapseML • Power BI • REST API

---

### 🏗️ [Medallion Architecture in Microsoft Fabric](https://github.com/Musili-Adebayo/Building-a-Medallion-Architecture-in-Mircosoft-Fabric)
A lakehouse implementation using Bronze, Silver and Gold layers to demonstrate ingestion, transformation, data modelling and analytics in Microsoft Fabric.

**Tech:** Microsoft Fabric • Lakehouse • PySpark • Data Modelling • Power BI

---

### 🔄 [Northwind Analytics Engineering with dbt & BigQuery](https://github.com/Musili-Adebayo/northwind-analytics-engineering-project-with-dbt-and-bigquery)
An analytics engineering project that transforms Northwind data from raw source tables into staging, dimensional warehouse and analytical layers using dbt and BigQuery.

**Tech:** dbt • BigQuery • SQL • Kimball Dimensional Modelling • Looker Studio

---

### 🗃️ [Northwind SQL Practice Repository](https://github.com/Musili-Adebayo/Northwind-Database)
A practical SQL repository containing business-focused queries and answers using the Northwind database.

**Tech:** MySQL • SQL • Data Analysis
